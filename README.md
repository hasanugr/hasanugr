### Hi, I'm Hasan 👋

Senior Full Stack Engineer (frontend-focused) from Türkiye with 10+ years of experience building web applications with **React, Next.js, TypeScript and Node.js**.

- 🏗️ Currently leading the frontend architecture of three enterprise SaaS products for construction inspection and lab management.
- 💳 Previously worked on fintech internal platforms: an API management portal, a notification panel (SMS, email, push) and an LLM-powered search app.
- 🤖 I work with an AI-first workflow every day, mostly with Claude Code.
- 🎮 I also built and published a few mobile games with Unity (e.g. [Drive And Destroy](https://play.google.com/store/apps/details?id=com.MoliteGames.DriveAndDestroy)).
